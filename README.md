# Gavhack
Gavhack for 1.7.2 is a Minecraft utility mod or "hack client" built using ModCoderPack to decompile minecraft.
Optifine has been added to the source code, and the mod itself is written in Kotlin.

## Why 1.7.2?
Gavhack is build on Minecraft version 1.7.2 for the server Alfheim.pw, and is primarily designed to be played on that server.
